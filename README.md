Nim 是一款免费开源的个人网站模板，基于 Next.js 16、React 19、Tailwind CSS v4 和 Motion 构建。它面向开发者、设计师和创业者，将极简设计与 [Motion-Primitives](https://motion-primitives.com) 提供的精致动画组件相结合。

在线演示：[https://nim-fawn.vercel.app](https://nim-fawn.vercel.app)

## 功能

- 极简的单页作品集布局。
- 支持 MDX 博客。
- 响应式与无障碍设计。
- 易于使用。
- 使用 [Motion-Primitives](https://motion-primitives.com) 提供动画组件。

## 快速开始

详细的配置步骤请参阅[安装指南](./INSTALLATION.md)。

```bash
git clone https://github.com/ibelick/nim.git
cd nim
npm install
npm run dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看效果。
